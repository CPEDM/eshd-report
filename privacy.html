개인정보처리방침 (Privacy Policy)

cs-addon-project(이하 "본 애플리케이션")는 사용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 Google API 서비스 사용자 데이터 정책을 준수하고 있습니다. 본 방침은 본 애플리케이션이 수집하는 정보와 그 사용 방식을 안내합니다.

1. 수집하는 정보 및 수집 방법

본 애플리케이션은 Google Apps Script 기반 부가기능으로 동작하며, 서비스 제공을 위해 최소한의 권한만을 요청합니다.

  • Google 계정 정보: 사용자 식별 및 권한 확인을 위한 이메일 주소
  • 스프레드시트 데이터: 사용자가 본 애플리케이션을 적용한 스프레드시트의 셀 내용 (인수인계 내역, 생산/보고 데이터)

2. 정보의 이용 목적

  • 구글 스프레드시트 내 데이터 자동 취합 및 인수인계 항목 표시
  • 일일 업무 보고서 서식 자동 생성 및 동기화
  • 사용자 작업 요청에 따른 스프레드시트 편집 기능 실행

Google API 서비스 사용자 데이터 정책 준수 (Google Limited Use)

본 애플리케이션의 Google API 사용 및 다른 앱으로의 정보 전송은 Google API Services User Data Policy(한정적 사용 요건 포함)를 엄격히 준수합니다.

"cs-addon-project's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements."

3. 데이터의 보관, 공유 및 제3자 제공 금지

  • 외부 서버 미전송: 본 애플리케이션은 사용자의 스프레드시트 데이터를 외부 제3자 데이터베이스나 자체 서버로 전송하지 않습니다.
  • 제3자 제공 금지: 사용자의 개인정보나 스프레드시트 데이터를 외부에 판매, 대여 또는 공유하지 않습니다. 모든 데이터 처리는 사용자의 Google Workspace / Google 드라이브 환경 내에서만 격리되어 수행됩니다.
  • 보관 기간: 본 애플리케이션 자체는 데이터를 별도 보관하지 않으며, 데이터는 사용자의 스프레드시트 삭제 또는 스크립트 연결 해제 시 즉시 접근이 차단됩니다.

4. 사용자의 권리 및 데이터 삭제

사용자는 언제든지 Google 계정 보안 설정(Google 계정 권한 관리)에서 본 애플리케이션의 접근 권한을 철회할 수 있습니다. 권한 철회 시 본 애플리케이션은 사용자의 데이터에 더 이상 접근할 수 없습니다.
